MA52078 Algebraic Number Theory

Semester

S2


Credits

5 credits


Synopsis

This course will go beyond the elementary number theory seen in Number Theory and Cryptography and study the algebraic properties of numbers and number fields. One of the main topics to cover will be the failure of unique factorisation in number rings and how one reconciles this using the ideal class group.


Content

Algebraic number fields, quadratic fields, cyclotomic fields, rings of integers, norms and traces, failure of unique factorization, the ideal class group. Further topics to be taken from: Dirichlet's unit theorem, Diophantine equations, p-adic numbers, the Hasse principle.


Assessment

Exam only
