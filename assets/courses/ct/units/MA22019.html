MA22019 Introduction to Data Science

Semester

S2


Credits

5 credits


Synopsis

You will explore methods for understanding large data sets, using data visualization, data wrangling and tools for spatial and text data analysis. The unit will draw on data sets from a variety of applications and use R to explore the data-analysis techniques.


Content

Data wrangling using R. Techniques for visualising data in R. Statistical analysis of text data. Spatial data analysis. Application of data science to analyse large-scale complex data sets


Assessment

100% coursework


Prerequisites

No prerequisites
